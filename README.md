Code wrriten by @wolf3213 @NightRunner7 and @NikosFuw </br>
</br>
Important! .txt files should be saved in the following manner: </br>
ρsol\_M\_[init_M]\_t\_[time]\_sigma\_[sigma_m].txt  </br>
</br>
[init_M] -> replace by value of 'Mi' used in Mathematica code. </br>
[time] -> replace by value of time of galaxy evolution used in Mathematica code in [Gyr]. </br>
[sigma_m] -> replace by value of fixed cross section in Mathematica file in [cm^2/g]. </br>
</br>
e.g: ρsol_M_10.1_t_1000_sigma_1.txt </br>
